# RemoteLink — بديل AnyDesk مفتوح المصدر (ويب + أندرويد)

تحكم عن بعد، مشاركة شاشة، ونقل ملفات **مباشر بين الجهازين (P2P)** عبر WebRTC، فالبيانات مشفّرة (DTLS) ولا تمر بأي خادم.

## الميزات
| الميزة | التفاصيل |
|---|---|
| رقم جهاز من 9 خانات | مثل AnyDesk، مع اسم للجهاز وقائمة اتصالات سابقة |
| طلب اتصال وقبول/رفض | مع تحديد الصلاحيات قبل القبول |
| وصول دون حضور | قبول تلقائي بكلمة مرور |
| مشاركة الشاشة | أي طرف يشارك شاشته، مع 4 مستويات جودة قابلة للتغيير أثناء الجلسة، ومع الصوت |
| التحكم عن بعد | الفأرة (يسار/يمين/وسط/تمرير) ولوحة المفاتيح؛ على الهاتف: نقرة = نقر، ضغط مطوّل = زر أيمن |
| **نقل ملفات محسّن** | سحب وإفلات ملفات **ومجلدات كاملة** مع الحفاظ على بنيتها، لصق ملف بـ Ctrl+V، طابور إرسال، سرعة ووقت متبقٍ، إلغاء، بلا حد للحجم |
| مزامنة الحافظة | إرسال نص الحافظة بضغطة |
| دردشة | مع إشعارات |
| صلاحيات حية | تفعيل/إيقاف التحكم والملفات والحافظة أثناء الجلسة |
| PWA | يمكن تثبيته كتطبيق على الكمبيوتر |

## 1) تشغيل نسخة الويب
```bash
cd server
npm install
node server.js        # افتح http://localhost:9000
```
لتجربته بين جهازين عبر الإنترنت ارفعه على أي استضافة تدعم HTTPS (مشاركة الشاشة تتطلب HTTPS).
الاستضافات المجانية المناسبة: Render أو Railway أو Fly.io (للخادم كاملاً)، أو Netlify/GitHub Pages لمجلد `www/` فقط مع خادم PeerJS السحابي الافتراضي.

> افتراضياً يستخدم التطبيق خادم الإشارة المجاني `0.peerjs.com` فلا تحتاج خادماً. للإنتاج استخدم خادمك (`server/`) وعدّل `www/config.js`.
> للشبكات المقيدة (بعض شبكات الجوال والشركات) أضف خادم **TURN** في `config.js` (مثل coturn أو Metered.ca).

## 2) التحكم الفعلي بالفأرة ولوحة المفاتيح
المتصفحات لا تسمح لأي موقع بتحريك الفأرة. لذلك على الجهاز **الذي تُشارَك شاشته** شغّل العميل الصغير:
```bash
cd agent
pip install -r requirements.txt
python agent.py            # أو --monitor 2 للشاشة الثانية
```
الصفحة تتصل به تلقائياً عند بدء المشاركة (يستمع على 127.0.0.1 فقط). على macOS امنح Terminal صلاحية «إمكانية الوصول».
لتوزيعه كبرنامج واحد: `pip install pyinstaller && pyinstaller --onefile agent.py`

## 3) بناء ملف APK
### الطريقة الأسهل (بدون تثبيت شيء): GitHub Actions
1. ارفع المشروع إلى مستودع GitHub.
2. سيعمل `.github/workflows/android.yml` تلقائياً.
3. من تبويب **Actions** ← آخر تشغيل ← حمّل `RemoteLink-apk`.

### محلياً (يتطلب Android Studio + JDK 17)
```bash
npm install
npm run android:init
npm run android:build   # الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```
الملفات المستلمة على أندرويد تُحفظ في `Documents/RemoteLink/`.

### ما يعمل على تطبيق أندرويد
- ✅ عرض شاشة الكمبيوتر والتحكم بها باللمس، نقل الملفات بالاتجاهين، الدردشة، الحافظة.
- ⚠️ **مشاركة شاشة الهاتف نفسه** غير مدعومة داخل WebView؛ تحتاج إضافة أصلية تستخدم `MediaProjection`، والتحكم بالهاتف عن بعد يحتاج `AccessibilityService`. هذه هي المرحلة التالية للتطوير.

## بنية المشروع
```
www/          تطبيق الويب (HTML/CSS/JS) — نفسه يُغلّف داخل APK
agent/        عميل Python لتنفيذ أوامر الفأرة/الكيبورد
server/       خادم Express + PeerJS اختياري
.github/      بناء APK تلقائياً
```

## الأمان
- كل الاتصالات مشفّرة طرفاً لطرف (WebRTC DTLS/SRTP).
- لا يبدأ أي اتصال دون موافقة صريحة أو كلمة مرور الوصول دون حضور.
- استخدم كلمة مرور قوية للوصول دون حضور، ولا تشغّل `agent.py` إلا أثناء الحاجة.
